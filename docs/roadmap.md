# Roadmap

_Status as of 2026-11-22: docs only. Scope comes from starbooru-server's `docs/checklist.md` › windows / linux / macos app._

## 1. Foundation

- [ ] Meson and Cargo build, lints, CI, the Flatpak manifest
- [ ] Window, navigation, light and dark, the accent
- [ ] Sign-in to the self-hosted instance, with a password and with a provider
- [ ] Gallery: grid, infinite scroll, sorts
- [ ] Viewer: image, GIF and video, zoom, previous and next

## 2. Daily use

- [ ] Search with tag autocomplete and typo correction
- [ ] Drag and drop, file and folder pickers, paste; uploads in chunks with progress
- [ ] Download to the Downloads folder without overwriting
- [ ] Tag editor, explore, saved searches, votes, related posts, recycle bin
- [ ] Media cache on disk with a size limit
- [ ] Waits out the server's and other sites' rate limits (in `starbooru-client`)

## 3. Everything the reference had

- [ ] Other boorus and library imports
- [ ] People in a post, the editor, the duplicate finder, share links
- [ ] Settings and administration

## 4. Linux

- [ ] Token in the Secret Service
- [ ] Sweet animations
- [ ] English and Italian
- [ ] Flatpak on Flathub
- [ ] Updates, through Flatpak
- [ ] Sync
